# Neimprom downloadable assets

This repository stores public downloadable model assets and their licences.

- `models/youtube-education/minilm-l6-v2/`: runtime-download education model, manifest and checksums.
- `neon-focus/models/v1/`: archived safety models and provenance/licences.

The Neon Focus website now belongs to [NeonFocus](https://github.com/susantanag2008-sudo/NeonFocus), under `website/`, and is hosted on Cloudflare Pages:
[neonfocus.neimprom.com](https://neonfocus.neimprom.com/).

GitHub Pages publishing for this repository is disabled. Raw GitHub asset URLs remain available. Do not restore website hosting here or add credentials, private data or backend source.
